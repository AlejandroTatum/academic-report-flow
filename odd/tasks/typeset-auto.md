# typeset.py auto

First part of "slice 8" of the academic-report-flow improvements (`docs/portal/mejoras-skill.qmd`): a deterministic
`typeset.py auto` so the agent stops hand-formatting `body.typeset.md`. Worktree `academic-report-automation-worktrees/typeset-auto`,
branch `feat/typeset-auto` (base main 5dfe263). The other slice-8 items (one visible `build` phase, auto-deliver, 12 -> 8 grouping) are not in this feature.

## Specs

S1. Source requirement (`docs/portal/mejoras-skill.qmd:80`): "Hoy el agente edita `body.typeset.md` a mano (`references/production.md:23-26`). Un modo `typeset.py auto` convertiría de forma determinista tablas desde líneas `a; b`, líneas `Figura: ...`, URL desnudas y fórmulas simples, y dejaría al agente solo los casos ambiguos." New subcommand `typeset.py auto <folder>`: it binds exactly like `bind` (same refusals, same files) and then formats `body.typeset.md` only when that file was missing or still byte-identical to `body.md`. A typeset body that already differs from `body.md` is never rewritten; the command says so. `body.md` is never touched. Exit code as `bind` (0 once bound, 1 when the bind is refused). A `body.md` that is not UTF-8 refuses with exit 1 and writes nothing.
S2. Bare URLs become autolinks `<https://...>`. Trailing sentence punctuation and an unbalanced closing parenthesis stay outside the link. URLs already inside `<...>`, a Markdown link `[text](url)`, inline code, a fenced code block (closed only by the marker that opened it) or indented code are left alone; emphasis marks and quotes around a URL stay outside the link.
S3. A line `Figura: caption (path.png)` becomes `![caption](path.png)` (png, jpg, jpeg, pdf, svg). No size attribute is added.
S4. A run of two or more consecutive list lines `- a; b; c` with the same number of cells, three or more, becomes a pipe table set apart by blank lines: an empty header row, a separator that right-aligns every column whose non-empty cells are all numbers, then one row per line. The draft holds no column names, so the header row is left empty for the agent. A `;` inside square brackets (`[@a; @b]`) or inline code does not split a cell; a run is converted whole or not at all; a last cell that is empty in every row (trailing `;`) is not a column.
S5. After formatting, `auto` lists what it left for the agent, one line each with the line number in `body.typeset.md`: tables without column names, runs of two-cell `- a; b` lines (possible two-column table, not converted), and lines that look like a formula (not converted: "fórmulas simples" are reported, never rewritten).
S6. `typeset.py check` (and so `doc_status` and the build gate) gains the check `table_headers`: it fails while a table in `body.typeset.md` has an empty header row, naming the lines.
S7. Help text, the module docstring, `references/production.md` (Typeset) and `docs/portal/mejoras-skill.qmd` describe the command.
